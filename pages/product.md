# Produkt

- Jetzt kommt die spannende Frage: welches Produkt nehmen wir uns heute vor?
- Idealerweise ist es nicht zu klein / einfach / 100x schon auf github und damit im Trainingsset der KI
- Aber auch nicht zu groß, damit es uns nicht überwältigt
- Idee von uns:
  - Command-Line Tool, um Operationen auf Dateien auszuführen
    - Anzahl Zeilen / Zeichen für Text-Datei bestimmen
    - Checksum für Datei berechnen (Mit verschiedenen Hash-Algorithmen)
    - Text in Datei ersetzen (via Regex)
    - Zeilen aus Datei entfernen, die Regex matchen (oder nicht matchen)
    - Upgrade auf TUI
- Oder ein Projekt, das ihr mitgebracht habt
  - Vielleicht auch ein Open-Source Projekt, das ihr nutzt und erweitern wollt
