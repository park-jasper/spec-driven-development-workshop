# Workshop Spec-Driven Development

## Allgemeines Setup
- Coding-Agent: [OpenCode](https://opencode.ai/de)
  - `npm i -g opencode-ai`

## Spec-Driven Development
- [OpenSpec](https://github.com/Fission-AI/OpenSpec)
  - `npm i -g @fission-ai/openspec@latest`
  - `openspec config profile` -> `Workflows Only`
    - `Propose change`
    - `Explore ideas`
    - `Apply tasks`
    - `Sync specs`
    - `Archive change`
  - Im Ordner: `openspec init`
- [AgentOS](https://buildermethods.com/agent-os)

## Projekt Ideen
- Command-Line File-Helper (in der Sprache deiner Wahl)
  - Features:
    - Anzahl Zeilen / Zeichen für Text-Datei bestimmen
    - Checksum für Datei berechnen (Mit verschiedenen Hash-Algorithmen)
    - Text in Datei ersetzen (via Regex)
    - Zeilen aus Datei entfernen, die Regex matchen (oder nicht matchen)
    - Upgrade auf TUI
- Open-Source Erweiterung
  - Bestehendes Open-Source Projekt, das ihr kennt und nutzt, dem ein Feature fehlt
  - Wichtig: Viele Projekte haben eine No-AI policy, macht nur PRs auf, wenn ihr sicher seid, dass ihr verstanden habt, was da am Ende rausgekommen ist
